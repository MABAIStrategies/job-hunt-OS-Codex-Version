# Social Banner Design Brief

## Deliverable

Create editable Figma frames for a Job Hunt OS release banner and roadmap teaser. Export platform-ready PNG files only after current platform size and crop rules are verified.

## Brand Defaults

- Brand: MAB AI Strategies
- Product: Job Hunt OS
- Tone: sharp, practical, executive, credible, AI-forward
- Primary palette: near-black `#111827`, electric blue `#2563EB`, white `#FFFFFF`
- Accent palette: signal green `#16A34A`, amber `#F59E0B`
- Typography: clean sans-serif, high contrast, no decorative script
- Visual style: product workflow signal, not abstract decoration

## Release Banner Concept

Headline: "Job Hunt OS"

Support line: "From job post to complete application workflow."

Proof strip:

- Compensation
- Resume
- Cover Letter
- Follow-Up
- Interview Prep
- Dashboard

CTA: "Pilot access by MAB AI Strategies"

## Roadmap Teaser Concept

Headline: "From Codex-native skill to deployable hiring platform"

Phases:

1. Codex-native operating package
2. Local workflow runner
3. Team pilot
4. Hosted SaaS foundation
5. Production launch

## Export Checklist

- Confirm current platform dimensions and crop rules before final export.
- Keep key text inside the center safe area.
- Create separate frames for feed, story, vertical video cover, and pin.
- Export PNG for static posts.
- Export MP4 only after motion version is built.
- Preserve editable Figma source frames and component naming.
