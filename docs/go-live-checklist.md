# Go-Live Checklist

Use this before treating Job Hunt OS as live, active, or customer-ready.

## Repository

- [ ] Repository visibility is private.
- [ ] README reflects current status and validation commands.
- [ ] Proprietary license is present.
- [ ] Security policy is present.
- [ ] CI validation passes on GitHub.
- [ ] No secrets, resumes, customer data, or generated personal packages are committed.

## Skill Package

- [ ] `skills/job-hunt-os/SKILL.md` passes validation.
- [ ] Runtime-specific legacy paths and tool names do not appear in migrated deliverables.
- [ ] References, schemas, templates, and examples are aligned.
- [ ] Truth policy is explicit and preserved.

## Product

- [ ] Roadmap separates local v1 from hosted SaaS work.
- [ ] Production architecture identifies Neon Postgres, OAuth, Stripe-hosted billing, tenant isolation, aggregate counters, and audit logs.
- [ ] Source distribution controls are legal and transparent.

## Launch

- [ ] Social platform dimensions are re-verified before final export.
- [ ] Figma banner frames are inspected and exported.
- [ ] FigJam roadmap is inspected and adjusted if needed.
- [ ] Release announcement copy is approved for each channel.

## Customer Pilot

- [ ] Pilot ICP and buyer are selected.
- [ ] Pilot success metrics are defined.
- [ ] Customer onboarding workflow is written.
- [ ] Support and escalation owner is assigned.
