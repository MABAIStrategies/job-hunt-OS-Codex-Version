# Release Announcement Template

Job Hunt OS by MAB AI Strategies turns a job URL, screenshot, pasted description, or target title into a complete application command center.

What it creates:

- current compensation estimate
- truthful role-specific resume package
- cover letter package
- application route detection
- recruiter, hiring-manager, and peer follow-up plan
- interview prep
- mock hiring-manager review
- knowledge-gap plan
- dashboard-ready tracking record

Built first as a Codex-native skill repo. Designed to become a platform-agnostic job-search operating system for teams that help people get hired.
