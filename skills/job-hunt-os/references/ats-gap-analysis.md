# ATS Gap Analysis

Run ATS analysis before final document delivery.

## Match Score

Compute a practical keyword match score:

`matched target terms / total target terms * 100`

Target terms include required skills, preferred skills, repeated job language, title language, tools, certifications, seniority signals, and responsibility verbs.

## Gap Table

Return missing terms grouped by:

- Critical required keyword
- High-value preferred keyword
- Tool or platform
- Culture or operating signal
- Certification or credential

For each gap, name where to add it:

- summary
- skills
- experience bullet
- cover letter
- LinkedIn profile
- knowledge-gap plan

## Red Flags

Surface title mismatch, seniority gap, date gap, missing required certification, location mismatch, and unsupported claim risk. Do not hide red flags; show how the package addresses or cannot address them.
