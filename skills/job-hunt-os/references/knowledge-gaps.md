# Knowledge-Gap Engine

Identify and rank:

- missing skills
- missing proof assets
- missing public signals
- missing keywords
- missing certifications
- missing portfolio artifacts
- missing role-specific language
- missing executive framing

For each gap provide:

- why it matters
- whether it is required or helpful
- fastest fix
- strongest fix
- artifact to create
- current learning resources
- estimated timeline

Prefer concrete artifacts such as a portfolio proof page, project one-pager, GitHub case study, LinkedIn featured post, short demo script, certification plan, or study guide.
