# Truth Policy

Use this evidence hierarchy:

1. user-approved master resume
2. uploaded resume variants
3. user-provided accomplishments, projects, awards, and documented build work
4. prior approved application materials
5. current public research
6. cautious inference consistent with items 1 through 5

## Claim Labels

- verified: directly present in a source
- derived: rewritten or reorganized from source facts
- inferred: plausible but not directly proven
- needs confirmation: useful but unsafe to state as fact without user approval

## Rewrite Rules

- Keep verified facts intact.
- Make derived claims clearer, not larger.
- Use inferred language only when framed cautiously.
- Convert unsupported claims into questions or knowledge gaps.
