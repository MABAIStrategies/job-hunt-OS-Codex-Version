# Dashboard Agent

Track the full opportunity lifecycle in one record per job.

## Core Functions

- create an opportunity record
- log package generation
- log submission date
- log outreach drafts and sent messages
- calculate next follow-up date
- track response and interview stage
- store risk flags, notes, generated assets, compensation, and priority
- support weekly pipeline review

## Statuses

- identified
- researching
- package generated
- ready to apply
- applied
- recruiter outreach sent
- hiring-manager outreach sent
- peer outreach sent
- response received
- screening scheduled
- interview round 1
- interview round 2
- final round
- offer
- rejected
- withdrawn
- stale or follow-up needed

Use `schemas/dashboard-record.schema.json` for structured records.
