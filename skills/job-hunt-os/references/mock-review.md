# Mock Hiring-Manager Review

Simulate how a likely hiring manager would evaluate the package.

## Return Format

- score out of 100
- recommendation: strong interview, possible interview, or pass
- top strengths
- top objections
- strongest element
- weakest element
- what feels vague or unsupported
- what feels highly credible
- exact edits that would improve the score

## Rubric

- role relevance
- outcomes
- credibility
- leadership signal
- technical fluency
- communication quality
- fit with current company priorities
- ATS alignment
